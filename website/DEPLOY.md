## Put the website in Chrome
1. Upload `website/` to a GitHub repository.
2. Enable GitHub Pages for that repository/folder (or use another static host).
3. Open the published HTTPS address in Chrome.
4. Replace the "Android APK — Coming soon" link with your actual APK release URL once you build the app.

## Build Android
Use Expo/EAS on a machine/account that can create an Android build:
`npx eas build -p android`
